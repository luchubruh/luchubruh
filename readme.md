### About This Space

Welcome to my open-source studio—a living archive of creative experiments, micro-interactions, design tokens, and architectural prototypes. Every repository here is built on a simple philosophy: software should feel effortless, tactile, and enduring.

### Selected Works & Collections

| Project | Focus | Stack |
| :--- | :--- | :--- |
| **[01. Kinetic UI](./kinetic-ui)** | Physics-based micro-interactions & gesture primitives | `TypeScript` · `Motion` |
| **[02. Monograph](./monograph)** | Distraction-free editorial typography & layout engine | `React` · `CSS Grid` |
| **[03. Chroma](./chroma)** | Perceptually uniform color palette generator for interfaces | `Rust` · `WASM` |
| **[04. Canvas](./canvas)** | Node-based shader playground and generative visual studio | `WebGL` · `GLSL` |

### Design Principles

* **Form Follows Feeling** — Mechanics matter, but emotional resonance makes an interface memorable.
* **Subtlety Over Spectacle** — Restraint in motion, typography, and color creates clarity and longevity.
* **Craft in the Details** — From sub-pixel alignment to keyboard accessibility, nothing is an afterthought.
